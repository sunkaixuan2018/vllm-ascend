Artificial intelligence inference is the process of running a trained machine learning model to generate predictions or outputs from new input data. Unlike training, which requires massive computational resources to update model weights over large datasets, inference focuses on efficiently executing a fixed model to produce results in real time or near-real time. As AI models have grown from millions to hundreds of billions of parameters, the challenge of performing fast, cost-effective inference has become one of the central engineering problems in the field. Large language models such as GPT, LLaMA, Qwen, and DeepSeek are autoregressive transformer architectures. During inference, they process an input sequence through a series of attention layers and feed-forward networks to produce a probability distribution over the vocabulary at each step. The model then samples or greedily selects the next token, appends it to the context, and repeats the process until a stopping criterion is met. This sequential decode phase is fundamentally memory-bandwidth-bound because, at each step, the model must read all of its parameters from memory to compute just a single output token. To accelerate inference, hardware vendors have developed specialized accelerators. NVIDIA's A100 and H100 GPUs deliver high memory bandwidth and support for tensor cores that accelerate matrix multiplications in mixed precision. AMD's Instinct MI300X offers a unified memory architecture with extremely high bandwidth. Huawei's Ascend 910 series integrates dedicated AI cores, vector cores, and high-bandwidth memory on a single die, with a custom interconnect fabric called HCCS for multi-chip scaling. Each of these platforms requires software stacks tuned to expose the hardware's capabilities to inference frameworks. The vLLM framework, developed at UC Berkeley, introduced the concept of PagedAttention to address memory fragmentation in the KV cache. Traditional inference systems allocated a contiguous block of memory for each sequence's key-value cache, leading to significant internal fragmentation when sequences varied in length. PagedAttention maps logical KV cache pages to non-contiguous physical memory blocks, analogous to virtual memory paging in operating systems. This dramatically increases GPU memory utilization and enables much higher throughput by serving more concurrent requests. Continuous batching, also known as iteration-level scheduling, is another technique that improves throughput in serving systems. Instead of waiting for all sequences in a batch to finish before starting new ones, the scheduler inserts new requests into the batch as soon as a slot becomes available. This keeps the hardware fully utilized and reduces average latency for requests that arrive when others in the batch are nearly complete. vLLM implements continuous batching alongside PagedAttention to achieve state-of-the-art throughput on both NVIDIA and Ascend hardware. Quantization is a widely used technique to reduce the memory footprint and increase the arithmetic intensity of inference workloads. By representing model weights and activations in lower-precision formats such as INT8, INT4, or FP8 rather than BF16 or FP32, quantization reduces memory bandwidth requirements and allows more parameters to fit on a given accelerator. Weight-only quantization stores weights in a compressed format but dequantizes them before computation, while activation quantization also converts intermediate tensors to lower precision, enabling the use of integer or low-precision matrix multiplication units that offer higher throughput. The attention mechanism is one of the most computationally intensive components of transformer inference. Standard multi-head attention computes queries, keys, and values for each head and performs scaled dot-product attention, resulting in quadratic complexity with respect to sequence length. Grouped-query attention, as used in LLaMA 2 and Qwen models, reduces the number of key-value heads while keeping the number of query heads constant, lowering the memory bandwidth required to load the KV cache during decoding. Flash Attention and its successors restructure the attention computation to maximize reuse of data in fast on-chip SRAM, substantially reducing the number of reads and writes to high-bandwidth memory. Tensor parallelism is a model parallelism strategy that splits individual weight matrices across multiple accelerators. In a transformer layer, the attention projection and feed-forward weight matrices can be partitioned along their column or row dimensions, with each device computing a partial result and exchanging data through an all-reduce collective at the end of each layer. This allows models that are too large to fit on a single device to be served across multiple chips, at the cost of introducing communication overhead proportional to the number of chips and the volume of exchanged data. Pipeline parallelism divides the model's layers across multiple devices such that each device processes a different micro-batch of data. While one device computes layers one through ten for micro-batch A, another device computes layers eleven through twenty for micro-batch B that arrived earlier in the pipeline. This approach is memory-efficient because each device stores only a subset of the model's layers, but it introduces pipeline bubbles when there is insufficient parallelism to keep all stages busy. Hybrid strategies that combine tensor and pipeline parallelism are used for very large models deployed across many accelerators. Speculative decoding is a technique that uses a smaller draft model to generate candidate tokens, which are then verified in parallel by the larger target model. Because the target model can verify multiple tokens in a single forward pass, speculative decoding can achieve super-linear speedups when the draft model's proposals are frequently accepted. The acceptance rate depends on the alignment between the draft and target models' distributions and is sensitive to the input domain and temperature setting. Variants such as medusa, EAGLE, and lookahead decoding extend the idea in different directions, generating multiple candidate continuations per step rather than relying on a separate smaller model. Key-value cache management is critical to the performance and correctness of inference systems. As context lengths grow to tens or hundreds of thousands of tokens, the KV cache can consume tens of gigabytes of memory per request. Prefix caching exploits the fact that many requests share a common system prompt or document prefix, allowing the KV cache for the shared portion to be computed once and reused across requests. Hierarchical caching strategies offload less recently used cache entries to slower memory tiers such as CPU DRAM or NVMe storage, retrieving them on demand when the corresponding tokens appear again in the context window. The Ascend NPU platform provides a software ecosystem centered on the CANN toolkit, which includes compiler optimizations, operator libraries, and profiling tools tailored to the Ascend architecture. The AscendCL runtime exposes the hardware through a C++ API that supports asynchronous execution, stream-based parallelism, and efficient memory management across host and device. The Ascend Profiling tool captures detailed traces of operator execution, memory transfers, and synchronization events, enabling engineers to identify bottlenecks and tune kernel configurations for specific workloads. Serving infrastructure for large language models must handle variable request arrival rates, diverse sequence lengths, and strict latency requirements simultaneously. Modern serving systems implement priority queues, preemption mechanisms, and admission control policies to balance throughput and latency under load. When the system is overloaded, requests may be preempted mid-generation and their KV caches swapped out to CPU memory or discarded, allowing higher-priority requests to proceed. The ability to efficiently manage these trade-offs determines the cost-effectiveness of deploying large models in production environments. Chunked prefill is a scheduling technique that limits the number of tokens processed in the prefill phase of a single scheduling step. By capping the prefill budget, the scheduler prevents long-context requests from monopolizing the hardware and starving short decode-phase requests that are waiting for their next token. This is particularly important for interactive applications where tail latency is critical. The prefill budget is typically set as a multiple of the decode batch size, ensuring that prefill and decode phases can be interleaved smoothly without causing significant latency spikes for either type of request. Memory bandwidth is the primary bottleneck for large language model inference at low batch sizes. Each token generated during the decode phase requires loading the full set of model weights from high-bandwidth memory, performing matrix-vector multiplications, and updating the KV cache. At small batch sizes, the arithmetic intensity—defined as the ratio of floating-point operations to memory bytes accessed—is low, meaning the hardware's compute units sit idle while waiting for data. Increasing the batch size improves arithmetic intensity because the same weights are used to process multiple sequences simultaneously, amortizing the memory access cost across more useful work. The evolution of transformer architectures has introduced several innovations that affect inference performance. Mixture-of-experts models replace dense feed-forward layers with a collection of expert networks, routing each token to a small subset of experts determined by a learned gating function. This increases the total parameter count while keeping the computational cost per token roughly constant, enabling models with hundreds of billions of parameters to be served at costs comparable to much smaller dense models. However, expert routing introduces load imbalance and communication overhead in distributed settings, requiring careful scheduling to maintain efficiency. Flash decoding and ring attention are techniques designed to improve the efficiency of attention computation for very long sequences. Flash decoding parallelizes the KV cache lookup across multiple thread blocks, reducing the latency of the attention operation during decode. Ring attention distributes the sequence across multiple devices in a ring topology, with each device attending to a local segment while passing key-value tensors to its neighbor. These approaches make it feasible to serve requests with context lengths of hundreds of thousands of tokens on current hardware, opening up applications such as document summarization, code repository analysis, and long-horizon reasoning. Compiler optimization plays an increasingly important role in extracting peak performance from inference hardware. Frameworks such as TVM, XLA, and torch.compile analyze the computational graph of a model, apply fusion rules to combine multiple operators into a single kernel, and generate optimized machine code for specific hardware targets. On Ascend, the CANN compiler performs operator fusion, tiling, and layout transformation to minimize data movement and maximize the utilization of AI cores and vector cores. Ahead-of-time compilation allows the system to amortize compilation cost across many inference requests, while just-in-time compilation enables dynamic shapes and new model architectures to be supported without manual kernel development. The deployment of large language models in cloud environments requires careful resource management to achieve high utilization and low cost.
