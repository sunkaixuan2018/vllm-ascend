Artificial intelligence inference is the process of running a trained machine learning model to generate predictions or outputs from new input data. Unlike training, which requires massive computational resources to update model weights over large datasets, inference focuses on efficiently executing a fixed model to produce results in real time or near-real time. As AI models have grown from millions to hundreds of billions of parameters, the challenge of performing fast, cost-effective inference has become one of the central engineering problems in the field. Large language models such as GPT, LLaMA, Qwen, and DeepSeek are autoregressive transformer architectures. During inference, they process an input sequence through a series of attention layers and feed-forward networks to produce a probability distribution over the vocabulary at each step. The model then samples or greedily selects the next token, appends it to the context, and repeats the process until a stopping criterion is met. This sequential decode phase is fundamentally memory-bandwidth-bound because, at each step, the model must read all of its parameters from memory to compute just a single output token. To accelerate inference, hardware vendors have developed specialized accelerators. NVIDIA's A100 and H100 GPUs deliver high memory bandwidth and support for tensor cores that accelerate matrix multiplications in mixed precision. AMD's Instinct MI300X offers a unified memory architecture with extremely high bandwidth. Huawei's Ascend 910 series integrates dedicated AI cores, vector cores, and high-bandwidth memory on a single die, with a custom interconnect fabric called HCCS for multi-chip scaling. Each of these platforms requires software stacks tuned to expose the hardware's capabilities to inference frameworks. The vLLM framework, developed at UC Berkeley, introduced the concept of PagedAttention to address memory fragmentation in the KV cache. Traditional inference systems allocated a contiguous block of memory for each sequence's key-value cache, leading to significant internal fragmentation when sequences varied in length. PagedAttention maps logical KV cache pages to non-contiguous physical memory blocks, analogous to virtual memory paging in operating systems. This dramatically increases GPU memory utilization and enables much higher throughput by serving more concurrent requests. Continuous batching, also known as iteration-level scheduling, is another technique that improves throughput in serving systems. Instead of waiting for all sequences in a batch to finish before starting new ones, the scheduler inserts new requests into the batch as soon as a slot becomes available. This keeps the hardware fully utilized and reduces average latency for requests that arrive when others in the batch are nearly complete.
